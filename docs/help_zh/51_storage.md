# 存储

**系统 -> 存储**显示 PBGui、PB7、PB8 及其 Python 环境的磁盘占用、可清理内容、历史变化和主机系统信息。

## 后台扫描

目录大小由后台扫描计算，并按配置的周期自动更新。打开页面时，如果上次扫描已过期，也会自动启动扫描。磁盘文件系统的实时占用始终单独更新。

## 概览与清理

- **磁盘**显示各文件系统的已用、可用空间和占用比例。
- 分类视图可以查看匹配的条目、大小和时间筛选结果。
- 清理操作先生成预览，再只删除明确选择的条目；受保护的市场数据、数据库、凭据、API 密钥和配置不会被 Storage 删除。
- 扫描和清理状态会自动更新，页面不需要手动刷新。

## 保留与历史

保留设置控制扫描周期和自动清理规则。历史视图按天记录磁盘使用量，并展示最近的增长趋势。

## 系统

系统视图显示 CPU、内存、Swap、运行时间、Python 版本、GPU、文件系统和 PBGui 进程。页面打开时这些值会自动轮询更新。
