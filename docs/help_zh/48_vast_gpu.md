# Vast.ai GPU 云端队列

云端优化已集成到 **PB8 优化**，不再提供独立的 Vast 系统页面。每个 PBGui
实例使用自己的 Vast 账户和余额。

## 设置与凭据

在 PB8 优化的 **Queue** 面板中展开 Vast GPU 云端区域，可保存 Vast API
密钥、Registry 令牌、GPU 要求和租赁限制。凭据只保存到本机的私有凭据目录，
不会写入浏览器存储，也不会复制到租用的 Worker 或机器人主机。

Vast API 密钥至少需要以下权限：

| 权限 | 用途 |
| --- | --- |
| `user_read` | 读取账户和余额 |
| `misc` | 搜索 GPU 报价 |
| `instance_read` | 读取实例状态和日志 |
| `instance_write` | 租用、启动、停止和删除实例 |
| `billing_read` | 查询实例费用 |

不需要 `billing_write`、`user_write` 或机器和团队管理权限。余额需要在 Vast
控制台单独充值；PBGui 不会自动充值或转移余额。

## 执行方式与 GPU 要求

在 PB8 优化配置编辑器中选择 **Execution → Vast GPU cloud** 或 **Local**。
选择 Vast 后，保存并入队会先针对固定的 Worker 镜像执行配置校验；校验失败时
不会准备云端任务，也不会启动租赁。GPU 类型、最高价格、最低显存、最低内存、
CPU 核数、磁盘大小和已验证主机偏好可在云端区域修改。

报价预览仅用于选择合适的 GPU 类型，不会保存或绑定某个报价 ID。默认排除 CUDA
版本低于 13、未知 CUDA 和租期不足的主机；打开 **Show incompatible hosts**
可查看排除原因。开始租赁时会再次搜索报价，并选择满足所有要求的单 GPU 主机中
小时价格最低的一台。若没有匹配报价，不会放宽要求，也不会偷偷创建替代租赁。

云端配置校验覆盖支持的指标、目标、限制、场景、Reducer、GPU 大小和边界。已保存
的配置不会被自动改写。数据可用性、文件上传和原生运行时检查属于后续阶段，配置
校验通过并不保证运行一定成功。

## 队列与租赁

**Prepare cloud job** 会为选中的 PB8 配置冻结本地输入并加入云端队列。多个任务
共用一次租赁，同一时间只运行一个优化任务。队列显示本地和云端任务，云端任务
会标记执行方式、GPU 和当前租赁状态。

使用 **Start rental** 前确认租赁和自动清理。PBGui 会使用已保存的租赁小时数、
预算和空闲清理设置搜索报价。租赁期限和预算适用于整个共享队列，后续任务不会
重置它们。输入文件按校验和缓存，任务仍保留自己的输入和输出目录。

- **Pause queue**：暂停后续任务启动，当前任务继续运行。
- **Resume queue**：恢复已有 Worker 上的队列调度。
- **Stop**：停止选中的任务并尝试收集结果。
- **Recover**：从控制器或主机中断后恢复现有租赁的监督，不创建替代租赁。
- **End rental**：暂停队列、停止并收集当前任务，然后删除 Worker；等待中的任务保留。
- **Requeue**：对失败或取消的任务创建新的冻结输入任务。

当没有可执行任务时，Worker 会立即删除或在设置的空闲时间后删除。确认
`deletion_verified` 后才表示实例已经完成清理；仅停止 Vast 实例可能仍产生磁盘费用。

## 进度、费用与恢复

任务面板显示租赁状态、截止时间、小时价格和费用估算。费用估算包括计算时间和
数据传输，Vast 的实际账单可能在一段时间内仍显示 **Pending**。日志、Pareto 和
结果会持续保存；完成任务后，原生结果和必要的元数据会导入 PB8 结果页面。

控制器重启或 PBGui 主机重启后，可以使用 **Resume supervision** 恢复本地监督。
固定截止时间的清理保护不会依赖浏览器页面。原始备份保存在
`data/vast/jobs/<job-id>/`，其中可包含检查点和日志。

该流程包含离线配置、队列、恢复、日志和浏览器回归测试。实际付费 Vast 端到端
验收仍需要在具备有效账户和余额的环境中单独执行。
