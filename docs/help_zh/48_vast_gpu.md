# Vast.ai GPU 云端队列

云端优化已集成到 **PB8 优化**，不再提供独立的 Vast 系统页面。每个 PBGui
实例使用自己的 Vast 账户和余额。

## 设置与凭据

在 PB8 优化的 **Queue** 面板中展开 Vast GPU 云端区域，可保存 Vast API
密钥、Registry 令牌、GPU 要求和租赁限制。凭据只保存到本机的私有凭据目录，
不会写入浏览器存储，也不会复制到租用的 Worker 或机器人主机。

Vast API 密钥至少需要以下权限：

| 权限 | 用途 |
| --- | --- |
| `user_read` | 读取账户和余额 |
| `misc` | 搜索 GPU 报价 |
| `instance_read` | 读取实例状态和日志 |
| `instance_write` | 租用、启动、停止和删除实例 |
| `billing_read` | 查询实例费用 |

不需要 `billing_write`、`user_write` 或机器和团队管理权限。余额需要在 Vast
控制台单独充值；PBGui 不会自动充值或转移余额。

## 执行方式与 GPU 要求

在 PB8 优化配置编辑器中选择 **Execution → Vast GPU cloud** 或 **Local**。
选择 Vast 后，保存并入队会先针对固定的 Worker 镜像执行配置校验；校验失败时
不会准备云端任务，也不会启动租赁。GPU 类型、最高价格、最低显存、最低内存、
CPU 核数、最低 TFLOPS、磁盘大小和已验证主机偏好可在云端区域修改。最低 TFLOPS 为 `0` 时不限制；报价预览和最终租赁选择都会重新执行该限制。

报价预览允许明确选择报价；手动 **Rent selected offer** 只租用该报价 ID，并在租赁前重新验证它仍可用且满足当前显示的硬件、价格和验证限制，不会静默换成另一台机器。默认排除 CUDA
版本低于 13、未知 CUDA 和租期不足的主机；打开 **Show incompatible hosts**
可查看排除原因。开始租赁时会再次搜索报价，并选择满足所有要求的单 GPU 主机中
小时价格最低的一台。若没有匹配报价，不会放宽要求，也不会偷偷创建替代租赁。

云端配置校验覆盖支持的指标、目标、限制、场景、Reducer、GPU 大小和边界。已保存
的配置不会被自动改写。数据可用性、文件上传和原生运行时检查属于后续阶段，配置
校验通过并不保证运行一定成功。

场景导出支持 Binance、Bybit、Bitget、OKX、Hyperliquid 和 KuCoin。每个 Suite 场景可以继承或覆盖交易所、币种、日期和受支持的 GPU 参数；PBGui 会对共享数据集去重，并为每个导出场所准备 mapping、首次 K 线和 warmup 元数据。错误会指出场景序号、标签和确切字段路径。源配置保持不变，嵌套覆盖只在冻结的 Worker 副本中展开。

## 主机历史、偏好与屏蔽

云端区域的 **Host management** 视图显示物理机器 ID、租赁次数以及 **Previously used**、**Working** 和 **Preferred** 状态。Working 来自实际完成的精确优化结果或手动标记；单纯创建过租赁不代表它工作正常。

- **Prefer host** 在既有价格、硬件和验证限制内优先选择该机器，不绕过兼容性检查。
- **Block host** 将机器排除在后续报价和租赁之外，但不会停止当前租赁。
- 偏好、可用标记和屏蔽均保存在本机队列状态中，可随时撤销；旧租赁只有在 PBGui 能安全解析其所属机器时才能操作。

## 队列与租赁

**Prepare cloud job** 会为选中的 PB8 配置冻结本地输入并加入云端队列。多个任务
共用一次租赁，同一时间只运行一个优化任务。队列显示本地和云端任务，云端任务
会标记执行方式、GPU 和当前租赁状态。

使用 **Start rental** 前确认租赁和自动清理。PBGui 会使用已保存的租赁小时数、
预算和空闲清理设置搜索报价。租赁期限和预算适用于整个共享队列，后续任务不会
重置它们。输入文件按校验和缓存，任务仍保留自己的输入和输出目录。

- **Pause queue**：暂停后续任务启动，当前任务继续运行。
- **Resume queue**：恢复已有 Worker 上的队列调度。
- **Stop**：停止选中的任务并尝试收集结果。
- **Recover**：从控制器或主机中断后恢复现有租赁的监督，不创建替代租赁。
- **End rental**：暂停队列、停止并收集当前任务，然后删除 Worker；等待中的任务保留。
- **Requeue**：对失败或取消的任务创建新的冻结输入任务。
- **Retry cleanup**：对已经结束但尚未确认实例删除的租赁重试清理，不会跳过待收集结果。

**Save & Queue** 在持久队列行创建后立即返回。本地 OHLCV 快照复制、清单生成和压缩继续在 API 所有的单线程准备器中运行；租赁只能在准备完成后启动。队列卡显示复制字节、文件数量、镜像层、rsync/上传重试和阶段进度。直接文件 rsync 使用严格验证的 SSH、内容哈希缓存和可恢复的部分文件；不支持 rsync 的旧 Worker 使用已验证分块回退。瞬态 SSH/网络错误会在 15 分钟无新进度前按 15/30/60 秒退避重试，而不是立即耗尽上传次数。

当没有可执行任务时，Worker 会立即删除或在设置的空闲时间后删除。确认
`deletion_verified` 后才表示实例已经完成清理；仅停止 Vast 实例可能仍产生磁盘费用。

## 进度、费用与恢复

任务面板显示租赁状态、截止时间、小时价格和费用估算。费用估算包括计算时间和
数据传输，Vast 的实际账单可能在一段时间内仍显示 **Pending**。日志、Pareto 和
结果会持续保存；完成任务后，原生结果和必要的元数据会导入 PB8 结果页面。

控制器重启或 PBGui 主机重启后，可以使用 **Resume supervision** 恢复本地监督。
固定截止时间的清理保护不会依赖浏览器页面。原始备份保存在
`data/vast/jobs/<job-id>/`，其中可包含检查点和日志。

活动租赁允许修改三项受保护的值：

- **Deadline adjustment** 接受 `-1440` 到 `1440` 范围内任意非零整数分钟，默认输入为 60。旧 guard 只在用户明确提交调整时升级；迁移期间 API 重启被阻止，失败会恢复旧 guard。
- **Budget target** 修改用户批准的共享租赁预算。
- **Transfer reserve** 修改输入和结果传输预留。PBGui 通过 Worker 确认的 compare-and-set 请求防止陈旧页面覆盖更新值。

自动刷新会保留当前租赁中尚未保存的预算、传输预留和分钟输入以及焦点；切换到另一租赁时草稿会重置。吞吐卡显示时间戳日志计数器计算出的 Proxy/min、Exact/min、累计值和估算 Exact/USD；超过 90 秒的样本不会伪装成实时速率。

## 性能历史

**Performance history** 由 API 约每 60 秒采集，即使浏览器未打开也会运行。私有数据库位于 `data/vast/performance.sqlite3`；删除队列任务不会删除历史。API 停止期间不采样，缺失的历史不能事后推算。

表格支持整行单击、Enter/Space 和拖动范围选择，最多选择四条。**View selected run** 查看单条记录；**Same workload only** 按第一条的工作负载指纹筛选全部历史；**Compare selected** 只允许相同且已验证的指纹，并显示 proxy/min 与 exact/min 的响应式 SVG 时间序列。页内筛选按配置、GPU、机器、币种和交易所匹配，Previous/Next 浏览旧记录。

指纹包含冻结配置、数据文件哈希、PB8 revision 和 Worker 镜像；排除任务路径、本地用户名和分配的 CPU Worker 数。种子、种群、目标、边界、场景和日期仍属于任务身份。GPU、CPU、内存和价格是对比轴，不会混入指纹。图表按实际覆盖秒数计算速率，计数器回退会断开区间，不跨重启制造吞吐。成本仅为容器时间和已观测传输量估算，不是 Vast 账单。

该流程包含离线配置、队列、恢复、日志和浏览器回归测试。实际付费 Vast 端到端
验收仍需要在具备有效账户和余额的环境中单独执行。
