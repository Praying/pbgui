# 仪表板

经过批准的 PBGui AI 仪表板创建或布局更改后，打开的 Dashboard 页面会刷新其列表并立即重新加载受影响的仪表板。重新加载是代次安全的：刷新进行中时的手动仪表板切换绝不会被延迟的 AI 完成覆盖。

**Dashboards** 页面为你的实时 Passivbot 实例提供完全可定制的投资组合总览。
你可以构建多组件布局、组合多个用户的数据，并自由地重新排列一切。

---

## 查看仪表板

- 如果只存在一个仪表板，它会自动打开。
- 如果存在多个仪表板，会出现一个**选择框**——选择你想要的仪表板。
- 所有仪表板都作为快速访问按钮列在侧边栏中。
- 组件在后台自动刷新。点击 ↻ 立即强制重新加载。
- 在编辑模式下，当组件的某个选择框、日期字段、数字字段或按钮处于活动状态时，实时刷新会推迟重建该组件。因此打开的 Period/User 控件保持打开，控件失去焦点后应用最新的待处理数据。
- Bitunix 和 WEEX PB8 用户使用 PB8 自己的只读客户端获取钱包余额、持仓、订单、价格/OHLCV 以及基于成交的已实现交易 PnL。这些客户端在隔离的短生命周期进程中运行，每次请求后关闭；有界快照避免重复的账户调用。
- Bitunix funding 收入无法从 PB8 v8.1.0 的连接器获取，因此其绩效组件目前覆盖基于成交的已实现 PnL 和费用，而不是声称完整的 funding 对等性。生产验收仍要求提供实时只读凭据，用于交易所响应和分页验证。
- 直接的 **Market close** 在 Bitunix 和 WEEX 上保持可见但禁用，直到每个交易所的对冲/单向和平仓订单合约分别经过实时测试。Panic、Graceful Stop 和 Take Profit Only 仍然可用，因为它们更新 Passivbot 配置，而不是猜测交易所订单参数。

## 侧边栏操作

| 按钮 | 操作 |
|--------|--------|
| ↻ | 重新加载当前仪表板 |
| ➕ | 创建新的空仪表板 |
| ✎ | 编辑当前显示的仪表板 |
| 🗑 | 删除当前仪表板 |
| 📋 | 打开 Templates 面板 |

**编辑**时，侧边栏切换为：

| 按钮 | 操作 |
|--------|--------|
| 💾 | 将更改保存到磁盘 |
| ✕ | 放弃所有更改并恢复之前的状态 |
| 🗑 | 永久删除当前仪表板 |

## 编辑器

单击 ✎ 在专用的全屏标签页中打开仪表板编辑器。

### 布局——行与列

顶部工具栏控制网格结构：

- **Name** — 侧边栏中显示的仪表板名称。
- **1 COL / 2 COL** — 在 1 列和 2 列网格之间切换。
  - **1 COL**：每行一个宽单元格——适合全宽图表。
  - **2 COL**：两个并排单元格——例如左侧 Positions、右侧 Orders。
- **Rows** — 使用 `+` / `−` 按钮添加或移除行。根据列设置，每行容纳 1 或 2 个单元格。

### 向单元格分配组件

每个单元格显示一个带**类型徽标**（如 `NONE`、`📊 PNL`、`📋 POSITIONS`、…）的标题栏。
单击徽标或从下拉框中选择类型来分配组件。
你也可以从工具栏右侧的**面板**（palette）**拖动**组件类型并将其放到单元格上。

### 拖放——重新排列组件

- **在编辑器中**：抓住单元格的深色标题栏（包含类型徽标和 🗑 图标的那个）并拖到另一个单元格上——两个单元格交换位置。
- **在实时视图中**：抓住组件的彩色标题栏（如 "Positions"、"Orders"）并放到另一个组件上以交换它们。交换自动保存到磁盘。

### 调整单元格大小

每个单元格的右下角有一个**调整大小手柄**。拖动它可使单元格变高或变矮。高度按单元格存储在仪表板中。

### 单元格配置面板

每个单元格在标题下方直接显示一个紧凑配置区：

- **Users** — 从哪些账户加载数据。`ALL` 表示所有账户，或选择特定用户。
- **Period / From / To / To now** — 时间范围控件（按组件类型可用）。
- **Link to Positions**（仅 ORDERS）— 一个芯片选择器，将 Orders 图表连接到同一仪表板中的特定 Positions 组件。
- **Mode**（PNL / ADG）— 在图表样式（柱状、折线等）之间切换。

## 组件类型

### ⚖️ BALANCE

显示一个或所有账户的**当前 USDT / USDC 余额、未平仓 PnL 和总权益**。
用户选择器直接嵌入组件标题中——没有单独的配置行。
最适合放在仪表板最顶部的紧凑摘要单元格。

### 📊 PNL — 每日 PnL

每个自然日已实现 PnL 的**柱状图**。
绿柱 = 盈利日，红柱 = 亏损日。
一条细的累计线叠加在柱上，显示整体趋势。

配置：
- **Mode** — `bar`（默认）或 `line`
- **Period** — 预设范围（`ALL_TIME`、`1_MONTH`、`3_MONTHS`、…）或自定义 From / To 日期
- **Users** — 按账户过滤

### 📈 ADG — 平均每日收益

USDT 余额随时间的累计**折线图**，显示整体增长曲线。
ADG 百分比（平均每日收益）显示在组件标题中。

与 PNL 相同的 Period 和 Users 控件。

### 📉 P+L — 每个符号的累计 PnL

在一个图表中为每个符号绘制**独立的累计 PnL 线**。
便于查看一段时间内哪些币种带来收益或亏损。

### 💰 INCOME — 按符号的收入

随时间的累计收入**折线图**，每个符号一条线。
有助于识别所选期间表现最好和最差的币种。

额外控件：
- **Last N** — 只显示按绝对值排名前 N 的符号
- **Filter** — 隐藏绝对值低于最低收入阈值的符号

### 🏆 TOP — 排名靠前的符号

按总收入对所有符号排名，并将前 N 个显示为水平柱状图。
亏损的符号显示为红色。适合快速查看绩效排名。

配置：
- **Top N** — 包含多少个符号
- **Period / From / To** — 时间范围

### 📋 POSITIONS

所选账户中所有当前未平仓持仓的**实时表格**。

列：User · Symbol · Side · Size · uPnL · Entry · Price · DCA · Next DCA · Next TP · Pos Value

- 新数据从交易所到达时，行会自动更新。
- **单击某行**可选择该持仓——关联的 **📝 ORDERS** 组件会立即加载该符号带订单标记的价格图表。
- 组件标题中的 Users 下拉框按账户过滤。

#### 管理持仓

Positions 标题旁边的 **Manage** 按钮打开一个可拖动、可调整大小的对话框，用于当前可见的持仓。

逐行操作：
- **Market close amount** 为所选行金额发送直接的 reduce-only 市价单。
- **Panic symbol** 保存感知运行时的按符号 forced-mode 覆盖并同步配置。
- **Graceful stop symbol** 保存感知运行时的按符号 `graceful_stop` forced-mode 覆盖并同步配置。
- **Take profit only symbol** 保存感知运行时的按符号 `tp_only` forced-mode 覆盖并同步配置。

对话框底部的所有持仓操作：
- **Preview Panic**、**Preview Graceful stop**、**Preview TP only** 显示将要保存的配置，不写入或同步任何内容。
- **Panic**、**Graceful stop**、**Take Profit Only** 为多空持仓保存相应的全局 PB7 或 PB8 强制模式。PB7 在其分配的 Cluster 机器人主机上立即推送并实体化。PB8 使用其经过验证的 bundle 保存，并为正常的 PB8 协调发布精确的 Cluster 操作。PB8 符号操作更新引用的稀疏覆盖 JSON，而不是错误地在主配置中嵌入 V7 风格的覆盖字段。

Exchange 用户必须恰好解析到一个本地 PB7 或 PB8 实例。如果同一用户被分配到多个实例或运行时，PBGui 会拒绝该配置操作，而不是猜测哪个机器人拥有该持仓。

Panic、Graceful Stop 和 Take Profit Only 是 Passivbot 配置/同步操作。它们不提交直接的交易所订单。当你明确希望 PBGui 发送直接 reduce-only 市价单时，请使用 **Market close amount**。

### 📝 ORDERS

一张**K 线图**，叠加所选持仓的订单标记（入场、止盈、DCA 订单），该持仓来自关联的 Positions 组件。

设置：
1. 同时添加一个 📋 POSITIONS 单元格和一个 📝 ORDERS 单元格（2 列布局效果最好）。
2. 在 ORDERS 单元格配置中，单击与 Positions 单元格匹配的 **Link to Positions** 芯片（如 "Row 3 · Col 1"）。
3. 在实时视图中，单击任意持仓行——图表自动加载。

控件：
- **Timeframe 按钮**（1m 5m 15m 30m 1h 2h 4h 6h 12h 1d 1w）——更改 K 线分辨率。
- 在图表上**向左滚动**可加载更早的历史 K 线。

## 模板

模板是**预构建的仪表板布局**，可作为起点使用。
不必从头构建网格，应用模板即可用合理的组件布局瞬间填充单元格。

### 应用模板

1. 在侧边栏中，单击 📋 **Templates**。
2. 打开一个面板，显示所有可用模板及小型预览。
3. 单击模板应用它——当前网格被替换为模板布局。
4. 调整每个单元格中的用户、期间和配置以匹配你的设置。
5. 单击 💾 保存结果。

> **注意：** 应用模板会覆盖当前网格。应用前请保存任何想保留的更改。

### 可用模板

| 模板 | 布局 | 内容 |
|----------|--------|----------|
| **Overview 2×3** | 2 列，3 行 | ⚖️ Balance、💰 Income、📊 PNL、📈 ADG、📋 Positions、📝 Orders |
| **Single user** | 1 列，4 行 | ⚖️ Balance、📈 ADG、📊 PNL、📋 Positions 垂直堆叠 |
| **Positions & Orders** | 2 列，1 行 | 📋 Positions 在左，📝 Orders 在右——自动关联 |

## 创建仪表板

1. 单击侧边栏中的 ➕。
2. 在对话框中输入**名称**，单击 **Create & Edit**。
3. 选择 **1 或 2 列**和**行数**。
4. 为每个单元格分配组件类型（从面板拖动或单击类型徽标）。
5. 配置每个组件（用户、时间范围、单元格之间的链接）。
6. 单击 💾——仪表板被保存并立即显示在实时视图中。

---

## 删除仪表板

1. 在编辑器中打开仪表板（✎）。
2. 单击侧边栏中的 🗑。
3. 确认删除。仪表板被永久移除。

---

## 提示

- 使用**2 列布局**，将 ⚖️ **BALANCE** 放在顶行跨两个单元格的位置，立即获得权益快照。
- 在 2 列布局中，把 📋 **POSITIONS** 和 📝 **ORDERS** 并排放置，点击持仓即可直接在相邻组件中打开其图表。
- 将 📈 **ADG** 和 📊 **PNL** 一起使用，比较长期增长与日常波动。
- 在实时视图中，通过拖动标题栏重新排列组件——无需打开编辑器。
- 使用 `ALL` 用户且单元格很多的仪表板可能加载较慢——分配特定用户以获得更好的性能。
