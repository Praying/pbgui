# 仪表盘

「仪表盘」页面现在是面向 Passivbot 账户的固定实时运营总览。页面采用一套经过确定的最佳布局，让重要数据进入页面即可看到，并保证所有用户看到一致的信息层级。

## 页面布局

页面按以下顺序展示：

1. **余额** — 总余额、未实现 PnL、总权益和账户明细。
2. **绩效** — 并排展示每日 PnL 与 ADG 图表。
3. **风险与执行** — 全宽展示当前所有未平仓仓位。
4. **活动** — 并排展示收入记录和热门交易对。

页面支持响应式布局。窄屏下的双列区域会自动堆叠，全宽区域仍然保持可访问。

## 实时更新

页面连接仪表盘实时更新通道。余额和仓位还会继续使用各自的实时轮询机制。数据更新只替换受影响的组件，不会刷新整页，也不会重置当前滚动位置。

页面顶部提供统一的「用户」「周期」和「模式」选项。用户和周期会同时应用到支持这些筛选的组件；图表模式会同时应用到 PNL 与 ADG 图表。这些选项只改变数据展示，不会改变固定页面布局。

## 固定行为

页面不再提供「新建仪表盘」、仪表盘选择、自定义布局编辑、删除或模板管理功能。固定总览是唯一的仪表盘展示方式，也不会写入用户自定义的仪表盘配置。

可以通过页面导航中的「Guide」查看本主题。浏览器刷新后仍会回到当前仪表盘页面。
